# KNTT GEOMETRY / MATH SYSTEM UPDATE — V2.3

Status: PASS

## System-wide math notation lock
All mathematical notation must follow GDPT 2018 and the Kết nối tri thức convention.

### Renderer
- Required: Math Engine / LaTeX-compatible renderer.
- Raw Unicode math symbols are forbidden in formulas.
- Plain-text glyph substitutes are forbidden.

### Examples
- `\perp`, not `⊥`
- `\parallel`, not `∥`
- `\in`, not `∈`
- `\sqrt{}`, not `√`
- `\frac{}{}`, not hand-built slash fractions in display math
- `\angle`, not `∠`
- `\Rightarrow`, not `⇒`

### Scope
Applies to:
- learning materials,
- worksheets,
- exercise sheets,
- assessments,
- video,
- geometry figures,
- solution steps.

### Preserved
- Geometry V2.2 rules.
- Layout V1.3 byte-identical.
