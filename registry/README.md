# MST-MATH Registry

This directory is the active authority and routing layer for MST-MATH.

It does not replace existing locked standards.

Rules:

1. MASTER has highest authority.
2. APPROVED artifacts cannot be overridden by lower-level module tasks.
3. Existing LOCKED/CANONICAL files remain source artifacts unless an explicit controlled migration supersedes their active identity.
4. Registry files point to authority; they do not redefine mathematics, layout, typography or geometry.
5. Renderers and output adapters consume semantic authority but never become the mathematical source of truth.
6. `PIMATH*` identifiers are compatibility/history only after `MST_MATH_CANONICAL_ID_MIGRATION_V1`; new canonical entries must use MST-MATH identity.
