# v1.6 Field Validation Evidence

This directory contains execution templates only. It contains no simulated or pre-filled human results.

Use anonymous tester IDs (`SELF-01`, `T01`) and classroom IDs (`CLASS-01`). Do not record names, emails, student answers, passwords, tokens, or other unnecessary personal data.

Run the tasks in `PILOT_TASKS.md`, preserve raw records, then rerun the field acceptance task. Empty evidence must remain `FIELD_ACCEPTANCE=PENDING_REAL_WORLD_EVIDENCE`.
