# v1.6 Pilot Plan

## Sequence

1. Teacher self-pilot: one operator completes PILOT-01 through PILOT-10.
2. External Wave 1: 2–3 teachers complete the common core and one specialized workflow.
3. Expand to Wave 2 only if friction clusters, correction burden, or evidence confidence require it.
4. Classroom validation: anonymous aggregate observations for student-facing worksheets, exports, figures, and videos.

## Evidence rules

Record actual start/end times, results, corrections, interventions, acceptance, and issue IDs. Preserve raw records; corrections require an audit note. Automated QA is not human acceptance.

## Release gate

Field acceptance requires real evidence, traceability, required Field Levels, zero open F3/F4 issues, and zero math errors in the accepted sample. No RC is created by this package.
