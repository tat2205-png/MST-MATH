# Production Workflow

## Phase A — Understand

1. Read all source materials.
2. Extract mathematical facts and geometry constraints.
3. Divide content into knowledge regions.
4. Define learning purpose for each region.

## Phase B — Design

1. Create master canvas layout.
2. Assign branch colors and visual roles.
3. Define camera targets and target widths.
4. Define narration cues.

## Phase C — Build

1. Reusable primitives first.
2. Main diagrams/formulas second.
3. Supporting cards/assets third.
4. Camera choreography fourth.
5. Audio synchronization fifth.

## Phase D — QA

Run static checks, then preview render representative frames, then runtime checks. Repair all mandatory failures before final render.

## Phase E — Final

Render final video, post-process only when needed, verify the final video visually and mathematically, and preserve the project as a reusable versioned artifact.
