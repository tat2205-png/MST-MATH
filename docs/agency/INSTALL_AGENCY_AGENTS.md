# Cài Agency Agents cho dự án

## Cách khuyên dùng
Cài ứng dụng Agency Agents chính thức, chọn công cụ bạn đang dùng (Codex, Cursor, Claude Code, Gemini CLI, ...), sau đó cài các nhóm: engineering, design, product, project-management, testing, security, specialized.

## Đội cần cho Math Workflow Studio
Agents Orchestrator, Product Manager, Multi-Agent Systems Architect, UX Researcher, UI Designer, Frontend Developer, Backend Architect, AI Engineer, Security Architect, Test Automation Engineer, Evidence Collector, Reality Checker, Document Generator, Corporate Training Designer.

## Khi làm việc trong repo này
Đọc `AGENTS.md` trước. Các agent toán học riêng của dự án nằm trong `agency/roles/` và được điều phối theo `agency-team-engine.js`.

## Cách giao nhiệm vụ
Bắt đầu bằng Agents Orchestrator, ví dụ:

`Use the Agents Orchestrator for Math Workflow Studio. Read AGENTS.md. Decompose this request, assign specialist owners and reviewers, enforce G2/G5/G6 gates, and do not release until the Reality Checker has evidence.`
