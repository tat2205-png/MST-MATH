# MST-MATH IDEA INDEX

**Status:** NON_PRODUCTION GOVERNANCE INDEX  
**Primary operating rule:** `MAKE CURRENT MST-MATH WORK — NO IMPROVEMENT YET`

This directory stores ideas and target directions so they are preserved without becoming production authority automatically.

## Master inventory

- [`MST_MATH_MASTER_IDEA_INVENTORY_V1.md`](./MST_MATH_MASTER_IDEA_INVENTORY_V1.md) — consolidated inventory of current canonical principles, accepted post-baseline targets, deferred modules, governance decisions, and rejected directions.

## Lifecycle

`CAPTURED → UNDER_REVIEW → ACCEPTED_TARGET → ADR/BACKLOG → IMPLEMENTATION → GOLDEN → PROMOTION → CANONICAL`

Allowed idea statuses:

- `CAPTURED`
- `UNDER_REVIEW`
- `ACCEPTED_TARGET`
- `PARKED`
- `DEFERRED`
- `REJECTED`
- `PROMOTED`

## Guardrail

Presence in `docs/ideas/` does **not** authorize implementation. Current locked production authorities and the current operating override remain controlling until an idea passes its promotion gate.
